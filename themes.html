A few things worth knowing before you pick

Every one of these is checked so the text passes contrast on its own background — which is why some call buttons carry dark text rather than white. Getting that wrong is the quickest way to lose the one click that matters on a trades site.

  • 02 would also change the type — hi-vis wants a heavier, more condensed headline face to match. The rest keep the current pairing.
  • 06 turns off light mode entirely, so it looks the same for everyone. The other five follow the visitor's phone setting, light or dark.
  • Mixing is fine — say "03 but with the orange call button" and that works.
  • Nothing else changes. The pages, the copy and the requirement builder stay exactly as they are; only the token block at the top of assets/site.css gets swapped.
